# 손에 든 attools

갤럭시·아이폰 홈 화면에 앱처럼 깔아 쓰는 한 화면짜리 도구다. **브라우저에서
돌 수 있는 것은 도구로 옮기고, 못 도는 것은 명령만 담았다.**

## 무엇이 들어 있나

| 탭 | 하는 일 |
| --- | --- |
| 도구 | 폰에서 진짜 도는 도구 21가지. 검색으로 찾는다 |
| 장부 | 수입·지출 적기, 달마다 남은 돈, 분류별과 지난달 대비, 되풀이된 지출 찾기 (`at sheet ledger`) |
| 고정비 | 구독·할부·보험을 한 달로 환산, 1년치, 곧 끝나는 것 (`at sheet budget`) |
| 더보기 | csv·json 내보내기와 되살리기, 비우기 |

**도구 21가지**

| 갈래 | 도구 |
| --- | --- |
| 계산 | 월급 실수령 · D-day/만나이 · 더치페이 · 대출 상환 · 적금/예금 · 4대보험 · 부가세/원천징수 · 통상시급/가산수당 · 주휴수당 · 퇴직금 · 연차 · 영업일/공휴일 · 전월세 전환 · 단위 변환 · 금액 한글 · 시간 계산 · 시차 |
| 글 | 조사 고르기 · 글자수/원고지 · JSON 훑기 |
| 표 | 붙여넣은 csv 훑어보기 · 검증 · 집계 |
| 찾기 | 단축키 찾기 · 명령 231개와 레시피 74가지 (`at find` · `at how`) |

### 브라우저에서 못 하는 것

폴더 정리(`at file`), git, 서버·포트(`at dev`), 워드·한글·PDF 열기는 브라우저가
파일 시스템을 만질 수 없어 옮기지 못했다. 없는 척하지 않고 **명령 찾기**에
그대로 담아 두었다 - 폰에서 찾아보고 PC 에서 치면 된다.

## 셈이 두 곳에 있는 문제

같은 셈이 폰과 PC 두 곳에 있으면 한쪽만 고치게 된다. 폰과 PC 가 다른
실수령액을 내는 것은 조용히 틀리는 쪽이라, `tests/test_mobile.py` 가

- 최저임금·4대보험 요율·주기 배수·일용근로소득세를 `attools` 상수와 대조하고
- 끼워 둔 명령·레시피·단축키가 지금 파서와 같은지 보고
- 도구가 적어 둔 «짝이 되는 명령» 이 진짜 있는 명령인지 본다

세 번째가 실제로 없는 명령(`at novel count`)을 잡아냈다.

## 폰에 까는 법

**한 대만 쓸 때 - 파일을 폰에 넣고 연다**

`mobile/` 폴더를 통째로 폰에 옮기고 `index.html` 을 브라우저로 연다.
그냥 쓰는 데는 문제가 없지만, `file://` 로는 서비스 워커가 등록되지 않아
오프라인 저장이 안 되고 «앱 설치» 도 뜨지 않는다.

**앱처럼 깔 때 - http 로 띄운다**

PWA 는 https(또는 localhost)로 받아야 설치된다. 집 와이파이에서 PC 가
띄워 주면 된다.

```bash
cd mobile
python3 -m http.server 8000 --bind 0.0.0.0
```

폰 브라우저에서 `http://<PC의 내부 IP>:8000` 을 연다. 삼성 인터넷·크롬의
메뉴에서 **앱 설치**(또는 홈 화면에 추가)를 누르면 런처에 아이콘이 생기고
주소창 없는 전체 화면으로 돈다. 한 번 열어 두면 그 뒤로는 PC 를 켜지 않아도
오프라인으로 돈다.

`0.0.0.0` 으로 묶으면 같은 공유기에 붙은 다른 기기도 열 수 있다. 가계부에는
개인 기록이 들어가므로 쓰고 나면 서버를 끈다. 공용 와이파이에서는 하지 않는다.

**계속 쓸 때 - 어딘가에 올린다**

정적 파일 다섯 개뿐이라 https 로 주기만 하면 어디든 된다(깃허브 페이지 등).
한 번 열면 서비스 워커가 캐시에 담아 그 뒤로는 오프라인이다.

## 어디에 저장되나

브라우저의 `localStorage` 에, **그 폰에만** 저장된다. 서버로 보내지 않고
다른 기기와 맞추지도 않는다. 브라우저 데이터를 지우면 같이 지워진다.

그래서 **내보내기·백업** 단추를 뒀다. 눌러 나온 csv 를 메모나 메일로 옮겨
두면 그것이 백업이고, PC 에서는 그대로 쓴다.

```bash
at sheet ledger 내보낸것.csv --date 날짜 --amount 금액 --name 내용 \
    --group 분류 --kind 구분
```

## 고칠 때

`index.html` 한 파일이다. 명령·레시피·단축키는 그 안에 끼워 두고
`tools/make_data.py` 로 다시 뽑는다 - 명령을 더했으면 이것을 돌려야 폰의
«명령 찾기» 가 따라온다.

```bash
python3 mobile/tools/make_data.py    # 명령·레시피·단축키 다시 넣기
python3 mobile/tools/make_icons.py   # 아이콘 png (표준 라이브러리만 쓴다)
```

판을 올리면 `sw.js` 의 `CACHE` 이름을 바꾼다 - 안 바꾸면 옛 캐시가 남아
고친 화면이 폰에 안 나온다.
