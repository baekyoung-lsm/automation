# 폰에서 쓰는 장부

갤럭시·아이폰 홈 화면에 앱처럼 깔아 쓰는 한 화면짜리 도구다. 터미널 없이
장부를 적고, 고정비를 모으고, 이번 달 실수령액을 본다. 적은 것은 csv 로
내보내 PC 의 `at sheet ledger` 에 그대로 물린다.

## 무엇이 들어 있나

| 탭 | 하는 일 | 터미널의 짝 |
| --- | --- | --- |
| 장부 | 수입·지출 적기, 달마다 남은 돈, 분류별 지출과 지난달 대비, 되풀이된 지출 찾기 | `at sheet ledger` |
| 고정비 | 구독·할부·보험을 한 달로 환산, 1년치, 곧 끝나는 것 | `at sheet budget` |
| 월급 | 월급·시급·일급·도급의 실수령액 (4대보험·주휴·연장 가산) | `at life wage` |

셈법은 터미널 쪽과 같다. 바뀌면 양쪽을 같이 고쳐야 한다
(`tests/test_mobile.py` 가 최저임금·요율 같은 수가 어긋나면 걸어 준다).

## 폰에 까는 법

**한 대만 쓸 때 - 파일을 폰에 넣고 연다**

`mobile/` 폴더를 통째로 폰에 옮기고 `index.html` 을 브라우저로 연다.
그냥 쓰는 데는 문제가 없지만, `file://` 로는 서비스 워커가 등록되지 않아
오프라인 저장이 안 되고 «앱 설치» 도 뜨지 않는다.

**앱처럼 깔 때 - http 로 띄운다**

PWA 는 https(또는 localhost)로 받아야 설치된다. 집 와이파이에서 PC 가
띄워 주면 된다.

```bash
cd mobile
python3 -m http.server 8000 --bind 0.0.0.0
```

폰 브라우저에서 `http://<PC의 내부 IP>:8000` 을 연다. 삼성 인터넷·크롬의
메뉴에서 **앱 설치**(또는 홈 화면에 추가)를 누르면 런처에 아이콘이 생기고
주소창 없는 전체 화면으로 돈다. 한 번 열어 두면 그 뒤로는 PC 를 켜지 않아도
오프라인으로 돈다.

`0.0.0.0` 으로 묶으면 같은 공유기에 붙은 다른 기기도 열 수 있다. 가계부에는
개인 기록이 들어가므로 쓰고 나면 서버를 끈다. 공용 와이파이에서는 하지 않는다.

**계속 쓸 때 - 어딘가에 올린다**

정적 파일 다섯 개뿐이라 https 로 주기만 하면 어디든 된다(깃허브 페이지 등).
한 번 열면 서비스 워커가 캐시에 담아 그 뒤로는 오프라인이다.

## 어디에 저장되나

브라우저의 `localStorage` 에, **그 폰에만** 저장된다. 서버로 보내지 않고
다른 기기와 맞추지도 않는다. 브라우저 데이터를 지우면 같이 지워진다.

그래서 **내보내기·백업** 단추를 뒀다. 눌러 나온 csv 를 메모나 메일로 옮겨
두면 그것이 백업이고, PC 에서는 그대로 쓴다.

```bash
at sheet ledger 내보낸것.csv --date 날짜 --amount 금액 --name 내용 \
    --group 분류 --kind 구분
```

## 고칠 때

`index.html` 한 파일이다. 판을 올리면 `sw.js` 의 `CACHE` 이름을 바꾼다 -
안 바꾸면 옛 캐시가 남아 고친 화면이 폰에 안 나온다.

아이콘은 `tools/make_icons.py` 로 다시 만든다(표준 라이브러리만 쓴다).
